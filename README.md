# Minimal Counter App

A lightweight and animated counter built with HTML, CSS, and JavaScript.

## Features

- Increment and decrement functionality
- Smooth animations on button press and number change
- Responsive and modern UI

## Demo

Open `index.html` in your browser.

## File Structure

 - index.html # Main HTML file
 - style.css # Custom CSS styles with animations
 - js.js # JavaScript logic for counter
 - README.md # Project documentation
